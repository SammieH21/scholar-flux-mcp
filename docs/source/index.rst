Welcome to Scholar Flux MCP's documentation!
=========================================

The Scholar Flux MCP server is a Python library that integrates the ScholarFlux library's core record retrieval and processing features with the Model Context Protocol, enabling the utilization of search, synthesis, and citation verification as composable tools.

Quick Start
===============

Installation
------------

The scholar-flux module is currently in beta, and is available right now for testing and preliminary use! Install Scholar Flux using the pypi index for testing:

.. code-block:: bash

   pip install scholar-flux-mcp
